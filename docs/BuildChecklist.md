# One-Week Build Checklist (No Errors)

## Day 1: Foundations
- Generate world seed; lock difficulty to easy/normal.
- Lay out Driftwake and Port Lumen coastlines.
- Build lighthouse, harbor market, and basic docks.
- Validate spawn point and tutorial quest flow.

## Day 2: Port Lumen City Core
- Complete Harbor Market, Guild Row, Cathedral Plaza.
- Add quest board, NPC signage, and lodging.
- Test fast-travel routes (boat or portal).

## Day 3: Greenfall Wilds
- Create forest biome, Warden grove, and ruins.
- Add puzzles, vines, and safe return paths.
- Playtest Wardens questline.

## Day 4: Cinderreach Forge
- Build volcanic terrain, forge district, steamworks.
- Add hazard signage and safe routes.
- Playtest Emberwright questline.

## Day 5: Zephyr Crest Sky Isle
- Build floating islands and cloud bridges.
- Add skybridge puzzles and safety nets.
- Playtest sky questline and glide sections.

## Day 6: Story and Polish
- Implement Mistcaller lore path.
- Add ambient sounds and resource pack assets.
- Place all Shardstone relics and reward chests.

## Day 7: Final QA
- Run full questline start-to-finish.
- Verify all quest hints and markers.
- Confirm resource pack loads without missing textures.
- Record final walkthrough and backup world.

## Validation Checklist
- All quests have objective markers and fallback hints.
- No dead-ends without a return route.
- All key doors/ports have keys or alternate access.
- Resource pack loads without errors.
- Spawn and hub are clearly signposted.
