# Custom Resource Pack Plan

## Pack Structure
- `pack.mcmeta` with description and format version.
- `assets/minecraft/textures/` for custom blocks/items.
- `assets/minecraft/models/` for custom item models.
- `assets/minecraft/sounds/` for ambient cues.

## Texture Targets
- **Shardstones**: Recolor amethyst shards to faction colors.
- **Faction Banners**: Custom banner patterns with logos.
- **Wayfarer Gear**: Rename leather armor with dyed textures.
- **Skyspindle Relic**: Custom carved crystal texture.

## Model Targets
- **Quest Compass**: Custom compass model that looks like a sextant.
- **Skybinder Key**: Custom key model for final quest.

## Audio Targets
- **Beacon Hum**: Low ambient loop near shard sites.
- **Quest Complete**: Short chime for quest turn-ins.

## UI/UX
- Custom advancement icons for each rank.
- Color-coded item names: 
  - Green = Warden, Orange = Emberwright, Blue = Mistcaller.

## Packaging Notes
- Keep file names lowercase and snake_case.
- Test resource pack in a clean instance before applying to map build.
