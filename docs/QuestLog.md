# Quest Log

## Main Questline
1. **Wreck of the Wayfarer** (Driftwake)
   - Objective: Gather supplies, craft a raft, light the lighthouse beacon.
   - Reward: Basic gear set, Rank 1.
2. **Light of Port Lumen** (Port Lumen)
   - Objective: Meet the Harbor League, deliver the beacon signal.
   - Reward: Access to quest board, map fragments.
3. **Wardens of Greenfall** (Greenfall)
   - Objective: Cleanse corrupted grove, obtain Verdant Shardstone.
   - Reward: Nature-infused tool, Rank 2.
4. **Forge of Cinderreach** (Cinderreach)
   - Objective: Repair lava sluice, gain Ember Shardstone.
   - Reward: Heatproof gear, forge access.
5. **Mistcaller Chronicles** (Port Lumen + Ruins)
   - Objective: Collect missing pages, learn Skyspindle truth.
   - Reward: Airship pass, lore unlock.
6. **Zephyr Crest** (Sky Isle)
   - Objective: Navigate skybridge, recover final Shardstone.
   - Reward: Rank 3, Skybinder blessing.
7. **The Skyspindle Reforged** (Port Lumen)
   - Objective: Align Shardstones, defend against saboteurs.
   - Reward: World restored, epilogue cutscene.

## Side Quests
- **Dockside Debts** (Port Lumen)
  - Collect ledgers from smugglers.
- **The Singing Stones** (Greenfall)
  - Restore ancient totems, unlock hidden glade.
- **Cinderreach Relay** (Cinderreach)
  - Repair steam line, open shortcut tunnels.
- **Lost at Sea** (Driftwake)
  - Find message bottles, map secret cove.
- **Skyglass Hunt** (Zephyr Crest)
  - Collect crystals for Mistcaller research.

## Optional Challenges
- Time trial: Glide between wind towers on Zephyr Crest.
- Puzzle vault: Align mirror beams beneath Port Lumen cathedral.
- Arena: Defend Harbor League docks from wave raids.

## Quest Design Notes
- Each quest has a visible objective marker and a fallback hint sign.
- Include at least one safety return path for every puzzle area.
